# 26.8.13 TIL

## ros2 build & launch
- 실제 로봇은 수십 개의 노드(카메라, LiDAR, 인지 등) -> 하나하나 끄고 키기 힘들고 켜는 순서 중요


## 실습 
- 배운 ros2 colcon, build에서 새로운 rclpy, rclcpp 노드 등록해서 새로 빌드해 봄


- 에러 
1. package 'sensor_cpp_pkg' not found → 패키지/실행파일 미등록 + 이름 불일치
2. No package metadata was found for demo-py-pkg → Python 패키지 install 트리 손상

---
- 트러블 슈팅
1. demo_cpp_pkg/CMakeLists.txt
- find_package(sensor_msgs REQUIRED) 추가
- lidar_filter_node 실행파일 등록 (add_executable + ament_target_dependencies)
- install(TARGETS ...)에 lidar_filter_node 추가
이유: lidar_filter.cpp 소스는 있었지만 실행파일로 등록이 안 돼 있었고, 이 코드가 쓰는 sensor_msgs(LaserScan) 의존성이 빠져 있었음.

2. demo_cpp_pkg/package.xml
- <depend>sensor_msgs</depend> 추가

3. demo_py_pkg/setup.py
- console_scripts에 safety_controller_node = demo_py_pkg.safety_controller:main 추가
이유: safety_controller.py가 실행파일로 등록 안 돼 있었음.

4. demo_py_pkg/package.xml
- <exec_depend>geometry_msgs</exec_depend> 추가
이유: 코드가 Twist(geometry_msgs) 메시지를 쓰는데 의존성이 빠짐.

6. demo_bringup/launch/robot_safety_system.launch.py

- package='sensor_cpp_pkg' → 'demo_cpp_pkg'
- package='control_py_pkg' → 'demo_py_pkg'

이유: 런치가 존재하지 않는 패키지 이름을 가리키고 있었음. 코드가 실제로 있는 패키지로 맞춤.

---
파일 수정은 아니지만 한 조치

- demo_py_pkg 클린 리빌드 (rm -rf build/demo_py_pkg install/demo_py_pkg 후 재빌드)
  - 3번 에러(No package metadata) 해결. 파일 내용 문제가 아니라, entry point 추가 후 증분 빌드가 install을 제대로 못 갱신해서 생긴 문제였음.
