## 벡터 내적/외적

- 내적(dot product)은 다음과 같이 정의

\mathbf{a} \cdot \mathbf{b} = a_x b_x + a_y b_y + a_z b_z = |\mathbf{a}|\,|\mathbf{b}|\cos\theta

- $\mathbf{a}\cdot\mathbf{b}=0$ 이면 orthogonal
- projection :  
\text{proj}_{\mathbf{b}}\,\mathbf{a} = \frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}\,\mathbf{b}

- 넘파이 코드로는 
``` python
# 내적
dot = np.dot(a, b) 
# 두 벡터 사이 각도 (라디안 → 도)
cos_t = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
theta = np.degrees(np.arccos(cos_t))
```

- 외적(cross product)은 3차원에서만 정의되며 담으과 같이 정의 

\mathbf{a} \times \mathbf{b} = \begin{bmatrix} a_y b_z - a_z b_y \\ a_z b_x - a_x b_z \\ a_x b_y - a_y b_x \end{bmatrix}, \qquad |\mathbf{a}\times\mathbf{b}| = |\mathbf{a}||\mathbf{b}|\sin\theta\

- 기하학적으로는 두 벡터가 만드는 평면에 수직인 법선 벡터, 크기는 두 벡터가 만는느는 평행사변형의 넓이, 방향은 오른손 법칙을 따름

- 로봇에서 활용
1. 평면의 법선 : 바닥, 테이블 위 세 점으로 평면의 수직 방향 구함 (비전, PCD에서 핵심)
2. 회전축 : 두 자세 사이의 회전축을 외적으로 구함(쿼터니언)
3. 좌표축 생성 : 두 방향만 알 때 외적으로 세번째 축을 구해 직교 좌표계 완성
4. 넓이/방향 판정 : 세 점이 이루는 삼각형의 넓이, 점이 선의 어느 쪽에 있는지 등등

- 넘파이 코드로는 
``` python
# 외적
c = np.cross(a, b)

# 세 점이 이루는 평면의 법선
P1 = np.array([0, 0, 0.]); P2 = np.array([1, 0, 0.]); P3 = np.array([0, 1, 0.])
normal = np.cross(P2 - P1, P3 - P1)     # 두 변의 외적
normal_unit = normal / np.linalg.norm(normal)
```

# linearly independent , basis, dimension, rank

- linearly independent :
c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k = \mathbf{0} 
을 만족하는 유일한 방법이 $c_1=\cdots=c_k=0$ 밖에 없는 경우 선형 독립 

- basis : 벡터공간 V를 span 하면서 동시에 linearly independent인 벡터들의 집합 

- dimension : 벡터 공간 V의 basis의 개수 / dim(A)

- rank : pivot의 개수, colum space의 차원인 Col(A)와 같음
- nullity : null space의 차원인 Nul(A)와 같음. Ax = 0 의 free variable의 개수 

- $m \times n$ matrix에서 rank + nullity = n 

- 동치관계 
1. A의 열 벡터들은 선형 독립이다.
2. A의 열 벡터들은 $\mathbb{R}^n$의 Basis가 된다.
3. A의 열공간의 Dimension은 n이다.
4. A의 rank는 n이다 nullity = .
5. A의 역행렬 $A^{-1}$이 존재하며 $\det(A) \neq 0$이다.

- 로봇에서 활용
1. GPS 위성이 몇개 필요한지 : 위치 3성분 + 시계 오차 1 = 미지수 4개 -> 독립적인 측정이 4개(rank = 4) 필요
2. 카메라 캘리브레이션에 점이 몇개 필요한지 : 추정할 파라미터 만큼 독립 정보 필요
3. 로봇 팔의 자유도 - 관절이 6개여도 자코비안의 rank가 5면 자유도는 5
