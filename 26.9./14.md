- 피드백은 강건성은 주지만 안정성은 보장 못함

## 1. 안정성이란?
**정의(BIBO)** : 크기가 유한한 입력(Bounded Input)에서 크기가 유한한 출력(Bounded Ouput)이면 안정. 유한한 입력에서 출력이 무한히 커지면 불안정

- **안정(stable)** : 어떤 값에 수렴
- **한계 안정(marginally stable)** : 일정한 진폭으로 진동
- **불안정(unstable)** : 발산

## 2. Poles & Zeros
- 극점      : 전달함수 -> $\infty$  / 분모를 0으로 보내는 s 값
- zeros    : 전달함수 -> 0         / 분자를 0으로 보내는 s 값 

- 시간응답은 극점을 지수로 갖는 항들의 합, 극점이 $s = a + jb$일 때 응답은

- **실수부** : a < 0 일때 수렴(절댓값 크면 빠르게 수렴), a > 0일 때는 발산
- **허수부** : b가 있으면 진동, b가 클수록 빠르게 진동

1. 극점의 실수부 와 허수부가 각각 시간응답의 무엇을 결정하는지 한 문장씩 쓰세요
- 실수부 : 시간응답의 수렴, 발산 여부 / 수렴 속도 결정
- 허수부 : 시간응답의 진동 속도 결정

2. 극점이 $s = -4 \pm 3j$인 시스템과 $s = -1 \pm 3j$인 시스템 중 더 빨리 정착하는 쪽과 그 이유를 쓰세요.
- $s = -4 \pm 3j$인 시스템의 실수부가 음의 방향으로 더 멀리 위치하기 때문에

3. 피드백 이득을 키울 때 시스템이 불안정해질 수 있는 이유를 지연 개념을 사용해 설명하세요.
- 지연이 생기면 바로 과거 오차로 생긴 피드백이 늦게 반영되게 된다. 이때 피드백 이득을 키우게 되면 현재 오차를 바로 잡는게 아니라 오버슈팅을 유발하게 되서 시스템이 불안정해 진다
