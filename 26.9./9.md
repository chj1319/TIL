## 개루프와 폐루프

![loop_image](/img/loop_image.png)

- **개루프** : 목표값 -> 제어기 -> 플랜트로 신호 한번 전달, 출력 확인 x
- **폐루프** : 센서가 출력을 재서 목표값과의 차이를 제어기에 전달(feedback)

| -  | 개루프 | 폐루프 |
| --- | --- | --- |
| 센서 | 불필요해 저렴하고 단순 | 필요해서 비용, 복잡도 증가 |
| 외란 대응 | 오차 그대로 | 자동 보정 |
| 모델 오차 | 모델 틀리면 결과도 틀림 | 자동 보정 |
| 안정성 | 문제 없음 | 잘못 설계하면 발진, 불안정 |
| 예 | 토스터, 세탁기 타이머, 스템 모터 | 에어컨, 서보, 드론 자세 제어 |
