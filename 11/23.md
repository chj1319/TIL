# [TIL] 트랜스포머(Transformer)의 토큰화, 임베딩, 그리고 Q·K·V 작동 원리

## 1. 토크나이저(Tokenizer)와 임베딩 테이블(Embedding Table)

### ① 토크나이징 (Text $\rightarrow$ Token IDs)
* **작동 방식:** 띄어쓰기나 문법 규칙으로 2번 나누지 않고, 미리 통계적 빈도수(BPE 등)로 구축된 **단어 사전(Vocabulary)**을 기준으로 문장 전체(띄어쓰기 기호 포함)를 한 번에 서브워드(Subword) 단위로 분할한다.
  * 예: `"고양이가 쥐를 잡았다"` $\rightarrow$ `["고양이", "가", " 쥐", "를", " 잡", "았", "다"]`
* **고정성:** 토크나이저의 분할 규칙과 각 조각에 부여된 고유 번호(ID)는 모델 학습 시작 전에 확정되며, **학습 중에는 절대 변하지 않는다.**

### ② 임베딩 테이블 (Token IDs $\rightarrow$ Vectors)
* **1:1 매핑 구조:** 단어 사전의 각 ID(행 번호)마다 고유한 $d$차원 실수 벡터 1개가 1:1로 매핑된 거대한 숫자 표(`단어장 크기 V × 토큰 차원 d`).
* **학습의 본질:** 학습(역전파) 시 ID 번호는 고정된 채, **각 행에 담긴 벡터의 좌표값(숫자)들만 수정**된다.
* **분포 가설(Distributional Hypothesis):** 수억 개의 문장 속 빈칸 맞히기 학습을 통해, 비슷한 문맥에 등장하는 단어들(예: `사과`, `바나나`)은 정답을 맞히기 위해 자연스럽게 벡터의 숫자 배열(방향)이 비슷해진다.

## 2. 위치 인코딩 (Positional Encoding / Embedding)

* **필요성:** 트랜스포머는 문장의 모든 토큰을 병렬로 한 번에 처리하므로 단어의 순서 정보를 별도로 주입해야 한다.
* **벡터 덧셈 방식:** 순서 번호(`1`, `2`, `3`...)라는 스칼라 값을 더하는 것이 아니라, **단어 벡터와 동일한 차원($d$)을 가진 위치 벡터**를 만들어 원소별 덧셈(Element-wise Addition)을 수행한다.
  * `최종 입력 행렬 X (N × d) = 단어 임베딩 (N × d) + 위치 임베딩 (N × d)`
* **Sin/Cos 방식의 특징:** 짝수 차원에는 $\sin$, 홀수 차원에는 $\cos$ 파동 값을 채워 넣는다. 값이 항상 $[-1, 1]$ 사이로 유지되어 원래 단어 의미를 훼손하지 않으며, 삼각함수의 성질 덕분에 토큰 간의 상대적 거리 계산이 용이하다.
* **구분:** 사인/코사인 수식을 쓰면 고정값이지만, 학습 가능한 위치 임베딩(Learned Positional Embedding)을 쓰면 위치 벡터 표의 숫자도 학습을 통해 변한다.

## 3. Self-Attention과 Q, K, V의 역할

### ① 행렬 단위 생성
* 입력 문장 행렬 $X(N \times d)$에 학습 가중치 행렬($W_Q, W_K, W_V$)을 곱해 문장 전체에 대한 **$Q, K, V$ 행렬 1세트**를 생성한다. (Multi-Head일 경우 헤드 개수 $h$만큼 쪼개어 병렬 연산)
* 쪼개진 토큰 조각(`"고양이"`, `"가"`)의 의미 결합은 전처리가 아니라 **어텐션 층에서 서로 높은 점수를 주고받으며 문맥 벡터로 합쳐지는 과정**에서 일어난다.

### ② 연산 과정 및 의미
$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

1. **유사도 계산 ($QK^T$):** 두 벡터의 내적(Dot Product) 값이 큰 양수일수록 방향이 일치(연관성 높음), 음수일수록 반대 방향(연관성 낮음)을 의미한다.
2. **정규화 ($\text{Softmax}$):** 내적 점수를 총합이 `1(100%)`인 확률 비율(Attention Score)로 변환한다. `1`에 가까울수록 정보를 많이 흡수하고, `0`에 가까울수록 무시한다.
3. **정보 결합 ($\text{Score} \times V$):** 계산된 연관성 비율만큼 실제 의미 데이터인 $V$를 가중합하여, 주변 문맥이 반영된 새로운 토큰 벡터를 출력한다.

### ③ Q, K, V의 변형 및 부분 활용 사례
* **Cross-Attention:** $Q$(질문/생성 문장)와 $K, V$(원본 문장/이미지 등 외부 데이터)를 서로 다른 출처에서 개별 생성.
* **KV Cache:** 추론 시 이전 토큰들의 $K, V$는 메모리에 캐싱해 두고, 새로 생성되는 토큰의 $Q$만 개별 계산하여 속도 최적화.
* **임베딩 검색 / RAG:** 문맥 벡터 합성이 필요 없고 문서 유사도 순위만 필요하므로 $V$ 없이 **$Q$와 $K$의 내적(유사도)만 단독 활용**.

## 4. 모델 학습 시 변하는 것 vs 변하지 않는 것

* **변하는 것 (Learnable Parameters):**
  1. 단어 임베딩 테이블의 벡터 값
  2. 위치 임베딩 테이블의 벡터 값 *(학습형 구조일 경우)*
  3. 어텐션 가중치 행렬 ($W_Q, W_K, W_V, W_O$)
  4. 피드포워드 신경망(FFN)의 가중치와 편향 *(전체 파라미터의 약 2/3 차지)*
  5. 층 정규화(LayerNorm)의 스케일($\gamma$)과 시프트($\beta$)
* **변하지 않는 것:**
  1. 토크나이저 분할 규칙 및 토큰 ID 매핑 사전
  2. 모델 하이퍼파라미터 ($d$, $h$, 레이어 수 등) 및 활성화/Softmax 수식
