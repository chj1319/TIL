# [TIL] 트랜스포머(Transformer) 아키텍처부터 학습·추론 최적화까지 총정리

## 1. 토크나이저(Tokenizer)와 임베딩 테이블(Embedding Table)

### ① 토크나이징 (Text $\rightarrow$ Token IDs)
- **작동 방식:** 띄어쓰기나 문법 규칙으로 2번 나누지 않고, 미리 통계적 빈도수(BPE 등)로 구축된 **단어 사전(Vocabulary)**을 기준으로 문장 전체(띄어쓰기 기호 포함)를 한 번에 서브워드(Subword) 단위로 분할한다.
  - 예: `"고양이가 쥐를 잡았다"` $\rightarrow$ `["고양이", "가", " 쥐", "를", " 잡", "았", "다"]`
- **고정성:** 토크나이저의 분할 규칙과 각 조각에 부여된 고유 번호(ID)는 모델 학습 시작 전에 확정되며, **학습 중에는 절대 변하지 않는다.**

### ② 임베딩 테이블 (Token IDs $\rightarrow$ Vectors)
- **1:1 매핑 구조:** 단어 사전의 각 ID(행 번호)마다 고유한 $d$차원 실수 벡터 1개가 1:1로 매핑된 거대한 숫자 표(`단어장 크기 V × 토큰 차원 d`).
- **학습의 본질:** 학습(역전파) 시 ID 번호는 고정된 채, **각 행에 담긴 벡터의 좌표값(숫자)들만 수정**된다.
- **분포 가설(Distributional Hypothesis):** 수억 개의 문장 속 빈칸 맞히기 학습을 통해, 비슷한 문맥에 등장하는 단어들(예: `사과`, `바나나`)은 정답을 맞히기 위해 자연스럽게 벡터의 숫자 배열(방향)이 비슷해진다.

## 2. 위치 인코딩 (Positional Encoding / Embedding)

- **필요성:** 트랜스포머는 문장의 모든 토큰을 병렬로 한 번에 처리하므로 단어의 순서 정보를 별도로 주입해야 한다.
- **벡터 덧셈 방식:** 순서 번호(`1`, `2`, `3`...)라는 스칼라 값을 더하는 것이 아니라, **단어 벡터와 동일한 차원($d$)을 가진 위치 벡터**를 만들어 원소별 덧셈(Element-wise Addition)을 수행한다.
  - `최종 입력 행렬 X (N × d) = 단어 임베딩 (N × d) + 위치 임베딩 (N × d)`
- **Sin/Cos 방식의 특징:** 짝수 차원에는 $\sin$, 홀수 차원에는 $\cos$ 파동 값을 채워 넣는다. 값이 항상 $[-1, 1]$ 사이로 유지되어 원래 단어 의미를 훼손하지 않으며, 삼각함수의 성질 덕분에 토큰 간의 상대적 거리 계산이 용이하다.
- **구분:** 사인/코사인 수식을 쓰면 고정값이지만, 학습 가능한 위치 임베딩(Learned Positional Embedding)을 쓰면 위치 벡터 표의 숫자도 학습을 통해 변한다.

## 3. Self-Attention과 Q, K, V의 역할

### ① 행렬 단위 생성
- 입력 문장 행렬 $X(N \times d)$에 학습 가중치 행렬($W_Q, W_K, W_V$)을 곱해 문장 전체에 대한 **$Q, K, V$ 행렬 1세트**를 생성한다. (Multi-Head일 경우 헤드 개수 $h$만큼 쪼개어 병렬 연산)
- 쪼개진 토큰 조각(`"고양이"`, `"가"`)의 의미 결합은 전처리가 아니라 **어텐션 층에서 서로 높은 점수를 주고받으며 문맥 벡터로 합쳐지는 과정**에서 일어난다.

### ② 연산 과정 및 의미
$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

1. **유사도 계산 ($QK^T$):** 두 벡터의 내적(Dot Product) 값이 큰 양수일수록 방향이 일치(연관성 높음), 음수일수록 반대 방향(연관성 낮음)을 의미한다.
2. **정규화 ($\text{Softmax}$):** 내적 점수를 총합이 `1(100%)`인 확률 비율(Attention Score)로 변환한다. `1`에 가까울수록 정보를 많이 흡수하고, `0`에 가까울수록 무시한다.
3. **정보 결합 ($\text{Score} \times V$):** 계산된 연관성 비율만큼 실제 의미 데이터인 $V$를 가중합하여, 주변 문맥이 반영된 새로운 토큰 벡터를 출력한다.

### ③ Q, K, V의 변형 및 부분 활용 사례
- **Cross-Attention:** $Q$(질문/생성 문장)와 $K, V$(원본 문장/이미지 등 외부 데이터)를 서로 다른 출처에서 개별 생성.
- **KV Cache:** 추론 시 이전 토큰들의 $K, V$는 메모리에 캐싱해 두고, 새로 생성되는 토큰의 $Q$만 개별 계산하여 속도 최적화.
- **임베딩 검색 / RAG:** 문맥 벡터 합성이 필요 없고 문서 유사도 순위만 필요하므로 $V$ 없이 **$Q$와 $K$의 내적(유사도)만 단독 활용**.

## 4. 모델 학습 시 변하는 것 vs 변하지 않는 것

- **변하는 것 (Learnable Parameters):**
  1. 단어 임베딩 테이블의 벡터 값
  2. 위치 임베딩 테이블의 벡터 값 *(학습형 구조일 경우)*
  3. 어텐션 투영 행렬 ($W_Q, W_K, W_V, W_O$) — *모두 `nn.Linear` 가중치 행렬로 학습됨*
  4. 피드포워드 신경망(FFN)의 가중치와 편향 *(전체 파라미터의 약 2/3 차지)*
  5. 층 정규화(LayerNorm)의 스케일($\gamma$)과 시프트($\beta$)
- **변하지 않는 것:**
  1. 토크나이저 분할 규칙 및 토큰 ID 매핑 사전
  2. 모델 하이퍼파라미터 ($d$, $h$, 레이어 수 등) 및 활성화/Softmax 수식

## 5. Multi-Head Attention의 분업 원리와 Tensor 분할

### ① 헤드별 역할 분담과 다양성이 유지되는 이유
- 여러 개의 헤드가 각자 독립적인 투영 행렬($W_Q, W_K, W_V$)을 가지고 문장을 서로 다른 관점(주어-서술어, 목적어-서술어, 시제, 수식어 등)에서 동시에 분석한다.
- **학습을 계속해도 헤드들의 가중치가 같아지지 않는 이유:**
  1. **무작위 초기화(Symmetry Breaking):** 출발 좌표가 다르므로 역전파 기울기(Gradient)의 이동 방향이 계속 달라진다.
  2. **오차 감소 경쟁:** 병렬 계산 후 $\text{Concat} \cdot W_O$로 합쳐져 전체 오차(Loss)를 채점받으므로, 다른 헤드가 이미 해결한 패턴은 기울기가 작아지고 각 헤드는 아직 해결되지 않은 빈틈을 찾아 전문화된다.
  3. **차원 병목 효과 및 드롭아웃:** 쪼개진 작은 차원($d_k = d_{model} / h$)에 모든 정보를 담을 수 없어 특정 패턴에 집중하게 되며, Attention Dropout이 헤드 간 동기화를 방지한다.
  4. **중복 헤드 억제:** 우연히 겹치는 헤드가 생기면 출력 투영 행렬($W_O$)이 해당 헤드의 비중을 낮추거나 $0$으로 억제한다.

### ② GPU 병렬 연산을 위한 Tensor 분할 (`view` $\rightarrow$ `transpose`)
$$Q : (B, L, d_{model}) \xrightarrow{\text{view}} (B, L, h, d_k) \xrightarrow{\text{transpose}} (B, h, L, d_k)$$
1. **`view` (차원 분할):** 마지막 $d_{model}$ 차원을 헤드 수($h$)와 헤드당 차원($d_k$)으로 쪼갠다.
2. **`transpose` (축 교환):** 토큰 길이($L$)와 헤드($h$)의 위치를 맞바꾼다. GPU 행렬 곱셈은 맨 뒤 두 차원 $(L, d_k)$끼리 수행되므로, $B \times h$개의 독립적인 행렬 곱을 한 번에 병렬 처리할 수 있게 된다.

## 6. 어텐션 마스크(Mask)와 자기회귀(Autoregressive)

### ① 키(Key) 차단 원리 ($-\infty$ 트릭)
- 보지 말아야 할 토큰의 Key를 차단하기 위해 Softmax 직전 내적 점수($QK^T$)에 $-\infty$를 덮어쓴다. ($e^{-\infty} = 0$이 되어 해당 토큰의 $V$ 정보가 `0%` 반영됨)
- **Padding Mask:** 배치(Batch) 길이를 맞추기 위해 채운 의미 없는 `[PAD]` 토큰을 무시할 때 사용.
- **Causal Mask (Look-ahead Mask):** 디코더가 미래 단어를 엿보는(컨닝하는) 것을 막기 위해 현재 위치보다 뒤에 있는 토큰을 가릴 때 사용.

### ② 학습(Training)과 추론(Inference)에서의 작동 차이
- **학습 시 (Teacher Forcing & 병렬 처리):** 출력을 다시 입력으로 넣지 않고 **정답 문장 전체를 한 번에 투입**한다. Causal Mask가 각 위치에서 미래 정답만 가려주므로, 단 1번의 행렬 연산으로 모든 토큰 위치의 다음 단어 예측 문제를 동시에 풀고 채점(Cross-Entropy Loss $\rightarrow$ 역전파 $\rightarrow$ AdamW 업데이트)한다.
- **추론 시 (자기회귀, Autoregressive):** 정답지가 없으므로 `<BOS>` 또는 프롬프트부터 시작해 **모델이 생성한 출력을 다시 입력 뒤에 이어 붙여 동일한 디코더 블록을 매 스텝 반복 통과**시키며 한 토큰씩 생성한다.

## 7. FFN(피드포워드 신경망)과 트랜스포머 아키텍처 유형

### ① FFN의 차원 확장 및 축소 메커니즘
$$\text{FFN}(x) = \text{Activation}(x W_1 + b_1) W_2 + b_2$$
- 어텐션을 통과한 각 토큰 벡터에 대해 위치별로 독립적인(Position-wise) 선형 변환을 수행한다.
- **차원 확장 ($W_1: d_{model} \rightarrow 4d_{model}$):** 학습된 가중치 $W_1$을 곱해 차원을 4배로 넓혀, 좁은 공간에 얽혀 있던 의미 패턴을 고차원 공간에서 선형 분리하기 쉽게 만들고 모델의 사실 지식을 저장하는 메모리 역할을 한다.
- **비선형성 및 축소 ($W_2: 4d_{model} \rightarrow d_{model}$):** 활성화 함수(`GELU` 등)를 통과시킨 뒤 잔차 연결(Residual Connection)과 다음 블록 전달을 위해 원래 차원($d_{model}$)으로 압축한다.

### ② 아키텍처 유형 비교
- **Encoder-Decoder (번역기, 요약기 등):** 인코더가 입력 원문(텍스트, 음성, 이미지)을 양방향 어텐션으로 해석해 $K, V$를 만들면, 디코더가 Cross-Attention으로 인코더의 $K, V$를 참조하며 결과물을 생성한다.
- **Decoder-Only (GPT, Llama, Claude 등 현대 LLM):** 인코더 없이 디코더 블록만 쌓은 구조로, 프롬프트 이해부터 답변 생성까지 동일한 디코더 구조를 반복 실행한다.

## 8. 추론(Inference) 최적화: KV Cache와 GQA

### ① KV Cache (동적 계획법의 메모이제이션 적용)
- **작동 원리:** 추론 시 가중치($W_K, W_V$)가 고정되어 있고 Causal Mask로 인해 과거 토큰은 미래 토큰의 영향을 받지 않으므로, 이전 스텝($1 \sim N-1$)의 $K, V$ 값을 GPU 메모리에 저장(Memoization)해 두고 Step $N$에서는 **새로 추가된 1개 토큰의 $Q, K, V$만 계산**해 기존 캐시와 결합한다.
- **특징:** 스텝당 중복 연산을 제거하여 생성 속도를 획기적으로 높인다($O(N^2) \rightarrow O(N)$). 학습 시에는 가중치가 매번 변하고 병렬 처리를 하므로 사용하지 않으며, 추론 시 하나의 답변 생성이 끝나면 폐기된다.

### ② GQA (Grouped-Query Attention)
- **공간적 그룹 공유:** 설계자가 정한 비율에 따라 $Q$ 헤드들을 인덱스 순서대로 균등 분할하여 조(Group)를 편성하고, **같은 그룹 내 $Q$ 헤드들이 하나의 $K, V$ 세트를 공유**한다. (예: $Q$ 헤드 8개를 4개씩 2그룹으로 묶고 $K, V$는 2세트만 생성)
- **서로 다른 결과 도출:** 같은 $K, V$를 공유하더라도 각 $Q$ 헤드의 투영 행렬($W_Q$)이 다르므로 서로 다른 질문을 던져 각기 다른 어텐션 결과를 뽑아낸다.
- **KV Cache와의 결합:** 같은 스텝 안에서는 그룹 내 $Q$ 헤드들이 하나의 $K, V$를 공유하고(GQA), 다음 스텝에서는 이전 스텝의 그룹별 $K, V$를 캐시에서 재사용(KV Cache)함으로써 GPU 메모리 용량과 대역폭을 대폭 절약한다.

## 9. 모델 확장성과 가중치 재사용 (Emergent Abilities & LoRA)

### ① 창발적 능력 (Emergent Abilities)
- 모델의 레이어 수, 파라미터 수, 연산량을 임계점 이상으로 키웠을 때 작은 모델에서는 보이지 않던 복잡한 추론(Chain-of-Thought), 맥락 내 학습(In-Context Learning), 코딩 능력이 계단식으로 급상승하며 나타나는 현상.
- **원인:** 다단계 하위 기술의 정확도가 곱해지며 임계점을 돌파하는 구조적 효과, 단순 암기에서 일반화된 알고리즘 회로 형성으로의 전환(Grokking), 이산적 채점 지표(0점/1점)의 비선형성 등이 복합적으로 작용한다.

### ② 가중치 재사용과 LoRA (Low-Rank Adaptation)
- 규격($d_{model}$, 토크나이저 등)이 일치하는 트랜스포머는 사전 학습된 가중치를 전이 학습, 멀티모달 조립(ViT + LLM), 모델 병합(Model Merging) 등에 폭넓게 재사용한다.
- **LoRA의 행렬 연산 원리:**
  $$h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r}(B A) x$$
  - 거대한 원본 가중치($W_0$)는 동결(Freeze)하고, 랭크($r$)가 매우 작은 저랭크 행렬 $A$(난수 초기화)와 $B$($0$ 초기화)만 학습하여 파라미터 수정량을 $1\%$ 미만으로 줄인다.
  - 추론 시에는 학습된 $BA$를 원본 행렬에 합산($W_{\text{최종}} = W_0 + \frac{\alpha}{r}BA$)할 수 있어 추가 지연 시간(Latency)이 발생하지 않는다.
